Nama Produk

Dirgahayu Anugrah Personal Portfolio

Website portofolio pribadi yang dibuat untuk memperkenalkan profil, pendidikan, keahlian, dan proyek yang telah dikerjakan oleh Dirgahayu Anugrah sebagai siswa kelas XII jurusan Rekayasa Perangkat Lunak (RPL).

Fungsi Utama

Website ini berfungsi sebagai media untuk:

Menampilkan profil dan informasi singkat tentang pengembang.

Menampilkan informasi pendidikan sebagai siswa kelas XII jurusan Rekayasa Perangkat Lunak (RPL).

Menampilkan keahlian di bidang pengembangan web dan perangkat lunak.

Menampilkan proyek yang telah dibuat untuk tugas sekolah dan latihan pribadi.

Menyediakan informasi kontak untuk menghubungi pengembang.

Menjadi media untuk memperkenalkan kemampuan dan hasil karya pengembang.


Website dibuat dengan tampilan yang modern, responsif, dan mudah digunakan.

Manfaat bagi Pengguna

Portofolio ini membantu pengguna untuk:

Mengenal profil dan latar belakang pengembang.

Melihat kemampuan dan teknologi yang telah dipelajari.

Mengetahui proyek yang pernah dikerjakan.

Melihat perkembangan kemampuan pengembang di bidang Rekayasa Perangkat Lunak.

Mendapatkan informasi kontak pengembang dengan mudah.

Menjadi media dokumentasi hasil karya dan kemampuan pengembang.

Proyek yang Ditampilkan

Beberapa proyek yang ditampilkan dalam portofolio antara lain:

Sistem Informasi Perpustakaan Sekolah, yaitu aplikasi web untuk mencatat peminjaman dan pengembalian buku serta dilengkapi dashboard admin.

Aplikasi To-Do List Harian, yaitu aplikasi pencatat tugas sederhana berbasis JavaScript dengan penyimpanan data di browser.

Company Profile Toko Online, yaitu landing page untuk UMKM lokal yang responsif dan dapat digunakan untuk promosi produk.


Cara Instalasi

1. Download Source Code

Download atau clone source code proyek portofolio dari repository GitHub.

2. Masuk ke Folder Project

Buka folder project menggunakan Visual Studio Code atau text editor lainnya.

3. Jalankan Website

Buka file index.html menggunakan browser.

Website juga dapat dijalankan menggunakan ekstensi Live Server pada Visual Studio Code.

Website dapat diakses secara online melalui:
